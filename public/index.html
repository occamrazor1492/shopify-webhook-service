Shopify Webhook Service

Independent service for processing Shopify webhooks and adding customer tags

Service Status

✅ Service is running

This service processes Shopify webhooks and adds appropriate tags to customers.

Webhook URL

Configure your Shopify webhooks to use the following URL:

https://[your-netlify-site].netlify.app/.netlify/functions/customer-tag-webhook

Documentation

For setup and configuration details:

  • See the README.md file in the project repository
  • Ensure your environment variables are properly configured in Netlify
  • Create the webhook in your Shopify admin panel
